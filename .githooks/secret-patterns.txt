# Padrões GENÉRICOS que barram o commit. Três campos separados por `%%`:
#
#     rótulo %% regex %% caminhos-isentos
#
# O separador não é `|` porque os próprios regex usam `|` para alternância.
# O terceiro campo pode ficar vazio.
#
# Comparado apenas contra as linhas ADICIONADAS no índice: remover uma ocorrência
# antiga nunca é barrado.
#
# ---------------------------------------------------------------------------
# ESTE ARQUIVO É VERSIONADO E PÚBLICO. Por isso guarda só o que vale para
# qualquer instalação — chave, hash, token, IP privado, MAC.
#
# Os padrões da SUA topologia (hostname de equipamento, domínio, faixa de rede
# própria) vão em `secret-patterns.local.txt`, que é gitignorado. Uma lista de
# termos proibidos publicada no repositório entrega de graça o esquema de nomes
# e confirma quais nomes importam — protegeria contra o vazamento acidental ao
# custo de fazer o vazamento deliberado.
#
#     cp .githooks/secret-patterns.local.txt.example \
#        .githooks/secret-patterns.local.txt
#
# O `pre-commit` carrega os dois e avisa quando o local não existe.
# ---------------------------------------------------------------------------
#
# O terceiro campo existe porque alguns desses valores são legítimos em lugares
# específicos — o plano de VLANs precisa declarar gateways, os templates de rede
# descrevem a topologia atual, e os `.example` existem para mostrar o formato.
# Isenção por caminho é explícita e revisável; supressão inline não seria.
