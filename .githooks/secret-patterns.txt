# Padrões que barram o commit. Três campos separados por `%%`:
#
#     rótulo %% regex %% caminhos-isentos
#
# O separador não é `|` porque os próprios regex usam `|` para alternância.
# O terceiro campo pode ficar vazio.
#
# São os padrões DESTE homelab, não uma lista genérica. Ferramenta de prateleira
# pega chave da AWS e token do GitHub; não pega o hostname do seu hypervisor nem
# a sua zona DNS — que é exatamente o que já vazou aqui, 25 versões seguidas.
#
# ⚠️ Ao mudar hostname, domínio ou faixa de rede, ATUALIZE ESTE ARQUIVO. Padrão
# desatualizado é pior que padrão nenhum: dá a sensação de estar protegido.
#
# O terceiro campo existe porque alguns desses valores são legítimos em lugares
# específicos — o plano de VLANs precisa declarar gateways, o template do
# OPNsense descreve a rede atual, e os `.example` existem para mostrar o formato.
# Isenção por caminho é explícita e revisável; supressão inline não seria.
#
# Comparado apenas contra as linhas ADICIONADAS no índice: remover uma ocorrência
# antiga nunca é barrado.
